Spark Connect is running in namespace {{ .Release.Namespace }}.

Reach it from your machine:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "spark-connect.fullname" . }} {{ $port }}:{{ $port }}

Then connect a client with:

{{- if .Values.auth.enabled }}

  sc://localhost:{{ $port }}/;token=<token>

Read the token with:

  kubectl -n {{ .Release.Namespace }} get secret {{ default (include "spark-connect.nameWith" (list . "auth")) .Values.auth.existingSecret }} -o jsonpath='{.data.{{ .Values.auth.secretKey | replace "." "\\." }}}' | base64 -d
{{- else }}

  sc://localhost:{{ $port }}
{{- end }}

The Connect endpoint is exposed with a token. The Service speaks plaintext gRPC and
the PySpark client sends a token to a host other than localhost only over TLS, so
terminate TLS at the Ingress or the Gateway and connect with:

  sc://<host>:443/;use_ssl=true;token=<token>
{{- else }}

The Service port speaks plaintext gRPC, and the PySpark client sends a token to a
host other than localhost only over TLS. Use the port-forward above, or put a
TLS-terminating proxy or load balancer in front of the Service and connect with:

  sc://<host>:<port>/;use_ssl=true;token=<token>
{{- end }}
